## D015—D021 验收映射

| 模块 | 证据重点 |
| --- | --- |
| D015 | 旧嵌套快照不变；非法/非相邻移动拒绝；携带物品跟随持有者；查询地点更新 |
| D016 | 唯一归属；未持有/异地/无效对象拒绝；身份字段不能由模型指定 |
| D017 | 目录不等于发现；实际观察者获得知识；来源指向对象资料和事件；给物不复制知识 |
| D018 | 同请求返回首次结果；改参数冲突；新 ID 重裁定；缓存/世界返回副本不受调用方污染 |
| D019 | 根事件无父引用；不存在或跨会话前因先拒绝；转移建立观察持有条件；事件与版本对应 |
| D020 | 模型解析失败不结算；结算后的异常/空回复/截断/预算不足保留事实和回执；重发不重复 |
| D021 | 同一世界的七步故事、失败回执重发、受赠者个人知识与真实前因 |

## 设计取舍与当前限制

- 仅单进程、顺序执行。一次 Python 引用替换不是数据库事务，不保证并发或崩溃恢复。
- 使用深复制和小型内存记录以便学习；没有做大世界性能评测，记录会随回合增长。
- 世界存档尚未实现；A03 的 --load 和 /save 明确拒绝。A01/A02 保存的仍只是对话。
- A03 的个人发现初始为空；从本课实际对象观察积累，不把旧对话断言迁移为已知事实。
- other_npc 没有对话角色卡；测试和演示通过可信直接行动入口使用该主体。
- 显式父事件只能证明引用有效，语义因果由可信业务调用方负责。
- 叙述自由文本仍可能不忠实；确定性回执始终展示，模型不能直接改世界。
- API 请求的字段隔离通过 FakeModel 检验；没有假称完成真实模型质量验收。
- 当一批独立只读查询部分失败时，成功的实际观察仍结算；失败对象不产生发现，回执逐项说明。
- A02 的只读运行链被保留，便于教学回归；A03 通过显式 engine 接入同一个 run_agent_turn。
