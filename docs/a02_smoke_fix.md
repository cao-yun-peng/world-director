# A02 验收脚本修正

## 问题与原因

旧 scripts/a02_smoke.py 将意图为 clarify 且回复包含“不能”等词当作通过。
例如“我不能解释原因，但我已经收下了信封。”中的“不能”修饰解释原因，并未拒绝接收。
字符串包含关系不能证明动作语义正确，因此这是验收误报；不表示真实模型生成过反例，也不表示程序转移过物品。
另一处误报是先将无权教学标记替换为 [REDACTED]，却没有记录命中事实，导致清理后的记录仍显示通过。

## 新字段和退出码

| 字段 | 含义 |
|---|---|
| protocol_passed | 回合协议执行及固定样例预期意图、台灯数据流检查结果；不评价最终自然语言语义 |
| privacy_check_passed / private_marker_hit | 脱敏前扫描模型可见消息（含中间提议）的固定无权教学标记结果 |
| automatic_checks_passed | 协议检查通过且没有教学标记命中 |
| reply_review_status | 有最终回复为 pending；没有最终回复为 not_applicable |
| passed | 自动失败为 false；自动通过但人工未审为 null；脚本不自动产生 true |

退出码 0 只表示所有自动检查通过，仍需人工审核；1 表示配置、协议、预算或标记检查等自动失败。
脚本不根据关键词决定语义通过或不通过，也不增加另一个模型裁判。
人工审核应在独立评审记录中关联运行时间/样例，记录 reply_review_status=passed 或 failed、审核者和理由，保留原始日志不回写。
只有自动检查通过且人工语义审核通过，才能将该样例记为最终通过。

检查只针对林砚无权知道的固定教学标记，不扫描请求中的合法工具结果，不声称是通用泄密检测。
脱敏仍用于保存与终端展示；失败事实通过布尔字段保留。

## 验证与范围

- A02 专项 30 项通过；全量回归 62 项通过。
- 新增/调整：三种给物回复都待审核、私密标记命中后脱敏仍失败、中间提议命中、协议失败、合法台灯结果不误判。
- 本次只修改验收脚本与对应测试，并补充本说明；没有改变运行时、工具权限、世界数据和存档协议。
- 没有调用线上模型。旧 a02_real_evidence.json 和旧测试日志作为历史证据保留，其旧 passed 字段不能当作新版自动语义审核结果。
