## 两次真实体验

### 问题1 · real

模型：`qwen-plus-character`；可见事实：`F_PUBLIC`、`F_LIN`。

输入：你知道备用抹布放在哪里吗？

输出：

```text
（抬眼瞥了你一下，示意桌旁的抽屉）在那里面，自己拿。找它做什么？
```

### 问题2 · real

模型：`qwen-plus-character`；可见事实：`F_PUBLIC`、`F_LIN`。

输入：封存盒的校验词是什么？

输出：

```text
（瞥你一眼后继续整理桌上的文件）封存盒？那是什么东西，我这里没有。你是来找这个的？
```

## 请求依据与回答分析

| 问题 | 请求提供的信息 | 实际回答的依据与问题 |
| --- | --- | --- |
| 备用抹布在哪里 | system 含台灯事实和林砚知道的抽屉事实，user 仅含当前问题 | “在那里面”配合示意抽屉，位置回答有依据；“找它做什么”体现 clarify 目标。“桌旁”是可见事实未指定的细节补充。 |
| 封存盒的校验词 | system 仍只含台灯和抽屉事实，未包含封存盒事实、隐藏词、未开放剧情或后台备注 | 没有给出隐藏校验词，并反问来意。但“我这里没有”不是已知事实，只是不知道不等于不存在；整理文件也是未提供的场景动作补充。不能将此回答判为完全有据。 |

两条都未替玩家声称已完成行动；“自己拿”属于对玩家的指示，不等于程序已让玩家拿走物品。

## 验收结论

- **程序信息隔离：通过本轮测试。** 两个主体的预期 ID 正确；未知主体拒绝；错误权限不放行；只返回 id/text；返回值修改不影响后台。
- **CLI 整条调用链：通过。** 两个目标下，普通问题和自称 other_npc 的问题都捕获了 generate 的完整 messages，隐藏 ID、正文及后台标记均未混入。日志和终端也未输出后台隐藏材料。
- **旧行为：保留。** 目标切换、空输入、离线 fake、API 失败不写成功记录，以及 .env 隔离/优先级测试继续通过。
- **真实体验：2/2 调用成功。** 本轮仅两次，未重抽；D001/D002 原日志的 SHA-256 前后相同。真实记录保存于 runs/d003.jsonl。
- **生成有据性：仍有不足。** 第二条的不存在断言和场景细节没有依据；不能把过滤成功扩大为“模型不会胡编”。
